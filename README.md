# 六级词汇本 v1.00.3

用于六级词汇学习和默写的单文件网页，包含 2995 个词条、150 页词表。页面入口为仓库根目录的 [index.html](index.html)。

## 版本与更新约定

版本采用 `v1.xx.x` 格式，中间段固定两位、末段一位。每次更新递增末段，例如 `v1.00.3 → v1.00.4`；末段到 `9` 后进位，例如 `v1.00.9 → v1.01.0`。

每次更新都将名称改为“六级词汇本 v1.xx.x”，同步修改浏览器标签标题、顶部名称、词表标题和本 README 的当前版本，并在下方追加更新记录。记录写明日期和实际新增、修改或修复的内容，最新版本放在最上方。后续维护要求同时保存在 [AGENTS.md](AGENTS.md)。

`v1.00.0` 至 `v1.00.2` 是根据实际 GitHub 提交补录的版本号；旧提交当时没有显示版本号，本次没有改写旧提交。日期均按北京时间记录。
